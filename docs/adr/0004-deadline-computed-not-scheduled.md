# 마감 상태는 크론/배치 없이 요청 시점에 계산

설문이 마감됐는지 여부는 별도 스케줄러(크론, 큐 작업 등)가 주기적으로 상태를 갱신하는 방식이 아니라, 설문을 읽거나 투표를 시도하는 매 요청마다 서버가 "현재 시각이 `closes_at`을 지났는가"를 즉석에서 계산하는 방식으로 판단한다.

스케줄된 백그라운드 작업 없이 배포·운영을 단순하게 유지하기 위한 선택이다 — 특히 Vercel 서버리스 환경에서 별도 크론 인프라를 두지 않아도 된다는 점에서 폴링 기반 실시간 갱신을 택한 `docs/adr/0002-polling-for-realtime-results.md`와 같은 맥락이다. 트레이드오프로, "마감 시각이 지나는 정확한 순간 알림을 보낸다"와 같은 이벤트 기반 동작은 이 방식으로는 만들 수 없다 — 필요해지면 별도로 재검토해야 한다.
