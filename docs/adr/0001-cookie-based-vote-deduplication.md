# 참여자 인증 대신 쿠키 기반 익명 중복 투표 방지

참여자는 로그인이나 계정 없이 투표한다. 같은 사람이 같은 설문에 두 번 투표하는 것을 막기 위해, 참여자 인증 대신 "이 브라우저는 이미 이 설문에 투표했다"를 표시하는 쿠키에 의존한다.

계정 기반 방식 대신 이 방식을 택한 이유는, 이 앱이 캐주얼하고 낮은 위험도의 동아리 투표를 대상으로 하기 때문이다 — 완벽한 중복 방지보다 참여 장벽을 낮추는 것이 더 중요하다. 쿠키를 지우거나 다른 브라우저/기기를 쓰면 다시 투표할 수 있다는 트레이드오프는 감수한다. 더 강력한 보장이 필요해지면, 참여자 계정 도입과 함께 이 결정을 다시 검토해야 한다.
