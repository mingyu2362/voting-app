# 결과 공개를 영구 플래그가 아니라 마감 여부로 실시간 계산

마감된 설문의 결과 공개 여부는 저장된 "공개됨" 플래그가 아니라, 매 요청마다 현재 시각과 `closes_at`을 비교해 그때그때 판단한다. 즉 운영자가 마감된 설문의 마감 시각을 미래로 연장하면, 이미 모두에게 공개됐던 결과가 다시 "투표한 사람만" 볼 수 있는 상태로 되돌아간다.

이 방식을 택한 이유는, "한 번 공개된 결과는 영구 공개"라는 예외 상태를 별도로 저장·관리하는 것보다 "마감 여부 = `closes_at`과 현재 시각의 비교"라는 단일 규칙으로 결과 공개 여부까지 함께 계산하는 편이 데이터 모델과 로직을 훨씬 단순하게 유지하기 때문이다. 트레이드오프로, 운영자가 마감을 연장하면 이미 결과를 봤던 사람 입장에서는 결과가 다시 숨겨지는 것처럼 보일 수 있다 — 이는 의도된 동작이다.
