# 03: 마감된 설문: 투표 차단 + 결과 전체 공개

**What to build:** 마감 시각이 지난 설문은 투표를 받지 않고(서버+UI 모두), 투표 여부와 상관없이 누구나 결과를 볼 수 있다. 마감을 연장하면 다시 원래 규칙으로 돌아간다.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 마감 시각이 지난 설문의 상세 페이지에서 투표 버튼이 비활성화되고(숨김 아님) 안내 문구가 표시된다.
- [ ] 마감된 설문에 투표를 제출하면 서버가 거부한다(클라이언트에서 버튼을 우회하더라도).
- [ ] 마감된 설문은 참여자의 투표 여부와 상관없이 누구나 득표수/퍼센트 결과를 볼 수 있다.
- [ ] 운영자가 마감된 설문의 마감 시각을 미래로 연장하면, 그 설문은 다시 "진행중"으로 취급되어 투표가 가능해지고, 결과는 다시 "투표해야 보임" 규칙으로 돌아간다.
- [ ] 마감 여부는 저장된 상태 값이 아니라 요청마다 `closes_at`과 현재 시각을 비교해 계산된다(ADR 0004).
