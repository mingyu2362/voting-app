# 04: 설문 상세: 마감까지 남은 시간 카운트다운

**What to build:** 마감 시각이 설정된 설문의 상세 페이지에서 "마감까지 남은 시간"이 실시간으로 표시된다.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 마감 시각이 설정된 설문의 상세 페이지에 남은 시간이 표시되고, 페이지에 머무는 동안 1초 간격으로 갱신된다.
- [ ] 카운트다운은 클라이언트 로컬 시계 기준으로 계산되며, 3~5초 서버 결과 폴링과는 별개로 동작한다.
- [ ] 마감 시각이 없는(무기한) 설문의 상세 페이지에는 카운트다운이 렌더링되지 않는다.
- [ ] 이미 마감된 설문에는 카운트다운 대신 마감 상태가 표시된다.
