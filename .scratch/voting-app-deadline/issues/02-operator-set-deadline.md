# 02: 운영자: 설문 마감 시각 설정/변경/해제

**What to build:** 운영자가 설문 생성 시 마감 시각을 선택적으로 지정할 수 있고, 생성 후에도 대시보드에서 마감 시각을 바꾸거나 없앨 수 있다. "지금 마감하기" 버튼으로 즉시 마감도 가능하다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 운영자가 설문을 생성할 때 마감 시각(날짜+시각)을 선택적으로 입력할 수 있다. 비워두면 `closes_at`은 null(무기한)이다.
- [ ] 운영자 대시보드에서 이미 만든 설문의 마감 시각을 나중에 설정/변경/해제(null로 되돌리기)할 수 있다.
- [ ] "지금 마감하기" 버튼을 누르면 `closes_at`이 현재 시각으로 설정된다.
- [ ] 세션이 유효한 운영자만 마감 시각을 설정/변경/해제할 수 있다.
- [ ] 질문/선택지는 여전히 생성 후 수정 불가 — 마감 시각만 예외적으로 수정 가능하다.
