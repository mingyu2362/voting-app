# 02: 운영자 로그인/로그아웃 (24시간 세션)

**What to build:** 운영자가 공유 비밀번호로 로그인하면 서명된 세션 쿠키가 발급되어 24시간 동안 유지되고, 로그아웃하면 세션이 종료된다. 세션이 없으면 운영자 전용 액션/라우트에 접근할 수 없다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 올바른 비밀번호로 로그인하면 서명된 httpOnly 세션 쿠키가 발급된다.
- [ ] 세션 쿠키는 발급 시점 기준 24시간 뒤 자동으로 무효화된다 (별도 서버 세션 저장소 없이 토큰 자체 만료).
- [ ] 틀린 비밀번호는 거부되고 쿠키가 발급되지 않는다.
- [ ] 로그아웃 액션 호출 시 세션 쿠키가 무효화된다.
- [ ] 세션이 없는 상태로 운영자 전용 액션(설문 생성/삭제 등)을 호출하면 거부된다.
- [ ] 공유 비밀번호(`ADMIN_PASSWORD`)는 클라이언트로 전달되거나 로그에 노출되지 않는다.
