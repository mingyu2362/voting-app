# 06: 참여자: 투표 제출 + 즉시 결과 확인 (중복 투표 방지)

**What to build:** 참여자가 선택지 하나를 골라 투표를 제출하면 voter_token 쿠키가 발급/확인되고, 같은 브라우저의 재투표는 거부되며, 투표 직후(또는 이미 투표한 상태로 재방문 시) 득표수+퍼센트 결과가 바로 보인다.

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 선택지 하나를 골라 제출하면 Vote 레코드가 저장되고, voter_token 쿠키가 없던 방문자에게는 새로 발급된다.
- [ ] 같은 voter_token으로 같은 설문에 다시 투표를 시도하면 애플리케이션 로직에서 거부된다.
- [ ] 애플리케이션 체크를 우회하는 상황(예: 동시 요청)에서도 DB의 `(poll_id, voter_token)` 유니크 제약이 중복 삽입을 막는다.
- [ ] 투표 제출 성공 직후, 선택지별 득표수와 퍼센트(및 총 투표수)가 화면에 표시된다.
- [ ] 이미 투표한 voter_token으로 같은 설문 상세 페이지를 재방문하면, 투표 폼 대신 곧바로 결과가 보인다.
- [ ] 한 번 제출한 투표를 변경하는 액션은 존재하지 않는다.
