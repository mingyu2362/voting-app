# 05: 공개: 설문 목록 + 설문 상세 (투표 전 화면)

**What to build:** 로그인 없이 누구나 전체 설문 목록(질문만)을 볼 수 있고, 설문을 클릭하면 선택지와 투표 버튼만 보이며 투표 전에는 어떤 숫자도(총 투표수 포함) 노출되지 않는다.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 비로그인 사용자가 설문 목록 페이지에서 존재하는 모든 설문의 질문을 볼 수 있다 (득표수 없음).
- [ ] 설문 목록에서 상세 페이지로 진입할 수 있다.
- [ ] 아직 투표하지 않은 방문자에게는 설문 상세 페이지에 선택지와 투표 버튼만 보이고, 득표수·퍼센트·총 투표수 등 어떤 숫자도 표시되지 않는다.
- [ ] voter_token 쿠키가 없는 최초 방문자에게도 위 규칙이 동일하게 적용된다.
