# 04: 운영자: 설문 삭제 (cascade)

**What to build:** 운영자가 대시보드에서 설문을 삭제하면 그 설문과 딸린 선택지·투표 기록이 함께 영구 삭제된다.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 세션이 유효한 운영자만 삭제 액션을 호출할 수 있다.
- [ ] 설문을 삭제하면 목록에서 즉시 사라진다.
- [ ] 삭제된 설문에 딸린 Choice, Vote 레코드도 DB에서 함께 삭제된다 (cascade).
- [ ] 삭제는 되돌릴 수 없다 (복구 기능 없음).
