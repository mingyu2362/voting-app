# 07: 결과 화면 자동 갱신 (3~5초 폴링)

**What to build:** 투표를 마친(또는 이미 투표한) 참여자가 보고 있는 결과 화면이 새로고침 없이 3~5초마다 자동으로 최신 득표수/퍼센트로 갱신된다.

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 결과가 보이는 화면에 머무는 동안 3~5초 간격으로 최신 결과가 다시 조회된다.
- [ ] 투표 전(선택지+버튼만 보이는) 화면에서는 폴링이 시작되지 않는다.
- [ ] 다른 참여자가 그 사이 투표를 추가하면, 폴링 중인 화면의 득표수/퍼센트가 자동으로 갱신된 값으로 바뀐다.
- [ ] 페이지를 벗어나면(언마운트) 폴링이 중단된다.
