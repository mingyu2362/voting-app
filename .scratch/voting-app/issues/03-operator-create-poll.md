# 03: 운영자: 설문 생성

**What to build:** 로그인한 운영자가 질문과 선택지(최소 2개)를 입력해 설문을 만들면, DB에 트랜잭션으로 저장되고 운영자 대시보드의 설문 목록에 즉시 나타난다.

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 세션이 유효한 운영자만 설문 생성 액션을 호출할 수 있다.
- [ ] 질문 텍스트와 선택지 2개 이상을 입력해 설문을 생성할 수 있다.
- [ ] 선택지가 1개 이하면 생성이 거부된다.
- [ ] Poll과 그 Choice들은 하나의 트랜잭션으로 저장되어, 실패 시 절반만 생성된 상태가 남지 않는다.
- [ ] 생성 직후 운영자 대시보드의 설문 목록에 새 설문이 나타난다.
- [ ] 생성된 설문의 질문/선택지를 수정하는 액션은 존재하지 않는다.
